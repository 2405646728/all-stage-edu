## 二、全局设计总则（与冻结文档逐条对应）

### 1. 学段判定（文档 12.2）
- 唯一判定依据：`sys_org.stage`（单机构固定单学段，含 CHECK 约束，禁止跨学段混绑）。
- 业务表以 `org_id` 强制机构隔离；关键主档表冗余 `stage` 列便于学段差异化统计与渲染。
- 学段枚举统一为：
  `kindergarten(幼儿园) / primary(小学) / junior(初中) / senior(普高) / vocational(职高) / university(大学)`

### 2. 数据隔离（文档 1.3.1-4、2.2）
- 所有业务表带 `org_id BIGINT UNSIGNED NOT NULL` 并建索引，应用层查询强制携带 org_id 条件；
- 表间采用**逻辑外键**（关联列 + 索引 + 注释标明关联表），**不建物理 FOREIGN KEY**——
  与文档「模块彻底解耦、无联表强依赖、可独立启停/熔断、支持单表独立迭代」的冻结原则一致，
  同时避免大数据量导入与分区运维时外键开销。跨表引用在 COMMENT 中逐一标注。

### 3. 通用字段约定（所有表统一）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT UNSIGNED AUTO_INCREMENT | 主键 |
| org_id | BIGINT UNSIGNED NOT NULL | 机构 ID（数据隔离；平台级表如 sys_ 全局表可不带） |
| created_by / updated_by | BIGINT UNSIGNED | 操作人用户 ID（留痕） |
| created_at / updated_at | DATETIME NOT NULL | 创建/更新时间（updated_at 自动更新） |
| is_deleted | TINYINT UNSIGNED NOT NULL DEFAULT 0 | 逻辑删除（1=已删；台账类表保留全量历史） |
| deleted_at | DATETIME NULL | 删除时间（可溯源） |

### 4. 工程规范
- 引擎 `InnoDB`、字符集 `utf8mb4`、排序规则 `utf8mb4_0900_ai_ci`；
- 金额一律 `DECIMAL(12,2)`；电话 `VARCHAR(20)`；身份证 `VARCHAR(18)`；
- 枚举用 `VARCHAR` 存码值 + `CHECK` 约束 + 注释枚举值（避免 ENUM 演进成本）；
- 每表、每列均有中文 COMMENT；台账表全部带操作留痕字段；
- 业务日期用 `DATE`，时间点用 `DATETIME`，纯标记用 `TINYINT`；
- 常用查询路径均建索引（机构/人员/日期/状态维度）。

### 5. 安全与合规（文档 1.3.2、5.2.1、12.5.3）
- 密码：`auth_user.password_hash` 存 BCrypt 摘要（由 Java 后端生成），**不存明文**；强制首登改密由 `must_change_pwd` 控制；
- 隐私字段（身份证号、健康档案、心理台账、家庭信息）由应用层对称加密后落库，字段 COMMENT 已标注「密文存储」；
- 财务操作日志（`fin_ledger_log`）与业务日志、运维日志（`sys_*_log`）三套隔离，永久留存；
- 账号开通全链路（批量导入/邮箱推送/重置）落在 `auth_open_batch / auth_open_item / auth_email_invite`，支持部分成功容错与撤回审计（文档 12.5.4）。

### 6. 冻结与拓展约定（文档 2.2、3.2）
- 本套表为「定稿冻结版」基线：后续迭代**不修改本批表结构**，新需求一律新增拓展表（前缀 `ext_`）并以可插拔模块接入；
- 统计类「基数看板」不建物化表，由应用层基于本套表实时聚合（保证数据唯一来源）。

## 四·五、测试数据说明（14_test_data.sql，仅限测试环境）

- 覆盖六学段：每学段 1 所机构 + 校管/班主任/学生/家长账号 + 全业务链路演示数据；
- 所有测试账号（含超级管理员 superadmin）初始密码统一为 `123456`（BCrypt 存储），并设置首登强制改密标志；
- 超管账号由占位值 `__INIT_REQUIRED__` 激活为可用状态；
- 本文件必须整体执行，且依赖 01~13 已导入；重复执行前请重建数据库。

## 五、初始化安全须知

1. `13_init_data.sql` 仅插入：学段字典、通用字典、六级角色、功能模块注册表、超级管理员占位账号；
2. 超级管理员占位账号 `superadmin` 的 `password_hash` 为占位值 `__INIT_REQUIRED__`，
   **必须由后端启动引导（或管理员脚本）初始化强密码后才可登录**，系统应校验该占位值并强制进入初始化流程；
3. 不预置任何机构、学生、收费等业务数据，避免污染正式环境。

## 六、与开发环境对接备忘

- JDK 21.0.11：JPA/MyBatis 均兼容本套 BIGINT UNSIGNED（Java 侧用 Long），DATETIME 映射 LocalDateTime；
- MySQL 8.0.45：已启用 utf8mb4_0900_ai_ci 与 CHECK 约束，8.0.16+ 均支持；
- Node v24.14.1：仅前端展示/联调用，数据库无相关依赖。
