## 后端模块规划（与冻结文档/表结构一一对应）

- `sys` 平台层：机构、校区、模块开关、字典、全局参数、角色权限、API 网关、门禁硬件、版本热补丁、告警、日志审计
- `auth` 账号体系：用户、角色绑定、批量开通、邮箱邀请
- `base` 通用底座：学年学期、年级班级、学生、学籍、监护人、师资、健康、文件
- `att/gate/msg/fin` 通用业务：考勤请假、门禁安防、通知消息、收费财务
- `kind/k12/senior/voc/uni` 学段专属：幼儿园接送餐食成长 / K12 教务德育 / 普高选科走班 / 职高实训实习 / 高校学分论文宿舍

> 数据契约说明：后端实体与 Mapper 严格按 `db/0X_*.sql` 的表结构（列名、类型、注释、索引）一一配对，任何表结构差异均以 db 文件为准。
