# 全学段一站式学生综合管理系统

![banner](./assets/banner-zh.png)

> 幼儿园 → 小学 → 初中 → 普高 → 职高 → 大学，一套源码、一套底层、一套权限体系，自适应全学段差异化办学场景。

**English version:** [README.en.md](./README.en.md)

---

## 项目简介

本项目是一套**国内首套真正意义上的全学段一体化学生综合管理系统**，覆盖从幼儿园到大学六个学段，支持多学校、多校区、多学段同时入驻独立运行，适配公办、民办、私立各类办学主体。

系统基于《全学段一站式学生综合管理系统（幼儿园-大学全覆盖｜最终定稿冻结版）》需求文档开发，数据库 135 张表与需求文档逐条一一对应，采用"统一底层基座 + 全学段可插拔模块化拓展"架构。

## ✨ 核心特性

- 🎓 **六学段全覆盖**：幼儿园 / 小学 / 初中 / 普高 / 职高 / 大学
- 🏗️ **四层解耦架构**：底层基座层 / 通用规则层 / 业务模块层 / 前端展示层
- 🔐 **金字塔六级角色权限体系**：超级管理员 → 校级管理员 → 教职工 → 学生 → 家长 → 访客
- 🛡️ **强数据隔离**：多机构 / 多学段数据底层强制隔离，单机构锁定单学段
- 🧩 **可插拔模块**：各学段功能独立封装，支持单独启停 / 熔断 / 热补丁
- 🌐 **学段差异化渲染**：一套前端代码动态适配六学段菜单与页面

## 📦 功能模块

### 平台超级管理员（sys）
机构入驻与学段管控、全局字典、全局参数、角色权限（菜单/按钮/数据三级 + 终审留痕）、操作/登录/接口日志审计、API 网关、门禁硬件全局注册、政务上报模板、版本迭代 / 热补丁 / 灰度发布、异常告警中心、IP 黑白名单、数据备份记录。

### 账号体系（auth）
六级角色统一账号、JWT + Redis 单端会话、**五大账号开通模式**（Excel / CSV 批量、班级一键生成、台账同步、单条开通、邮箱推送一键确认），唯一查重 + 部分成功容错 + 强制首登改密。

### 通用底座（base）
学年学期、年级班级（学段自动判定）、学生主档、学籍自动建档与异动台账、分班调班历史、多监护人绑定、师资与一人多岗、健康档案（加密隔离）、统一文件库。

### 通用业务（att / gate / msg / fin）
学生与教职工考勤、请假审批（联动缺勤）；门禁通行记录全量溯源 / 通行权限 / 陌生拦截预警 / 访客预约；通知分层发布 / 已读回执 / 一对一消息 / 推送模板；收费项目 / 账单 / 缴费入账 / 减免抵扣 / 财务独立日志。

### 六学段专属
- **幼儿园**：接送授权核验 / 接送记录红色预警、餐食公示、午休活动、成长纪实、晨午检、异常健康闭环、安全巡查整改
- **K12（小学/初中）**：课程 / 排课 / 调课、教学纪实、校本资源库、考试 / 成绩 / 学情分析、德育奖惩积分、班级量化考核、谈心心理、五维综合素质评价
- **普高**：新高考 3+1+2/3+3 选科规则、学生选科审核锁定、分层走班、等级赋分、高考备考台账、升学去向
- **职高**：专业、实训场地设备、实训计划与评分、职业资格考证、校企合作、顶岗实习（打卡 / 周月报 / 企业评价）、就业台账
- **高校**：院系专业、培养方案、开课选课（容量校验）、成绩绩点 GPA、补考重修、学业预警、六维综测、奖学金、科创竞赛、社团、论文答辩、学位预审、宿舍四级架构、报修服务、就业签约、体测健康

## 🚀 快速开始

### 环境要求

- JDK 21.0.11
- MySQL 8.0.45（含库 `all_stage_edu`）
- Redis 5.0.14.1
- Node.js v24.14.1

### 初始化数据库

按 `db/` 目录内 01~13 SQL 依次导入，测试数据可再导入 14（含六学段演示账号，见下）。

```bash
mysql -uroot -p < db/01_init_database.sql
mysql -uroot -p all_stage_edu < db/02_sys_platform.sql
# ... 03~13
mysql -uroot -p all_stage_edu < db/14_test_data.sql   # 可选：演示数据
```

### 启动后端（8080）

```bash
cd backend
mvn -DskipTests package
java -jar target/all-stage-edu.jar
```

### 启动前端（5173）

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173（同一局域网其他设备可经 http://<本机IP>:5173 访问）。
